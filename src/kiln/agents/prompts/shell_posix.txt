You are running commands on a POSIX system (Linux or similar). The companion
executes them in the shell named in your environment block (usually bash).

Rules for this OS:
- Prefer dedicated tools (read_file, write_file, edit_file, glob, grep, list_dir)
  over shell for file work. Reserve shell for installs, tests, builds, and
  version checks.
- Chain with `&&` when a later step must not run if an earlier one fails.
- Activate a venv with `source .venv/bin/activate`. Prefer calling the venv
  interpreter directly: `.venv/bin/python -m pytest …`.
- Prefer `python3` over `python` when probing the system interpreter.
- Quote paths that contain spaces with single or double quotes.
- Every shell command is shown to the user and runs only after they approve it.
  If they refuse with feedback, read the feedback and adapt. Never invent a
  successful result after a refusal or a tool error.
